# 🐍 python-labs

Repositorio personal de aprendizaje y práctica en Python, estructurado de forma progresiva desde los fundamentos del lenguaje hasta el desarrollo de APIs REST con FastAPI.

---

## 🗺️ Estructura del Repositorio

| Módulo / Carpeta | Descripción | Estado |
| :--- | :--- | :---: |
| 📂 **[01_fundamentos](./01_fundamentos)** | Sintaxis base, tipos de datos, estructuras (`list`, `tuple`, `set`, `dict`), control de flujo, funciones, POO, manejo de excepciones y módulos. | ✅ Completado |
| 📂 **[02_ejercicios](./02_ejercicios)** | Ejercicios prácticos de lógica, resolución de problemas y scripts de consolidación. | 🚧 En progreso |
| 📂 **[03_backend_fastapi](./03_backend_fastapi)** | Desarrollo de APIs RESTful, validaciones con Pydantic, rutas, esquemas y conexión a bases de datos con FastAPI. | 🔜 Próximamente |

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** Python 3.x
* **Framework Web / API:** FastAPI + Uvicorn
* **Validación de Datos:** Pydantic
* **Control de Versiones:** Git & GitHub

---

## 🚀 Cómo ejecutar los archivos localmente

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/TU_USUARIO/python-labs.git](https://github.com/TU_USUARIO/python-labs.git)
   cd python-labs
   ```
2. Para ejecutar cualquier script de fundamentos o ejercicios:
   ```bash
   python 01_fundamentals/00_hello.py
   ```
3. Para el entorno de **FastAPI** (dentro de `03_backend_fastapi`), consulta las instrucciones específicas en su propio [`README.md`](./03_backend_fastapi/README.md).
